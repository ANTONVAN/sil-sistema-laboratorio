# SIL — Sistema de Información de Laboratorios

Sistema de gestión para laboratorios clínicos.

## Stack
- **Backend:** Bun + TypeScript (Arquitectura Hexagonal)
- **Frontend:** React
- **Base de datos:** PostgreSQL

## Estructura
- `apps/api/` — Backend
- `apps/web/` — Frontend
- `infra/` — Docker, CI/CD, Observabilidad
- `docs/` — Documentación y decisiones de arquitectura
